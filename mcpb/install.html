Yggdrasil for Claude Desktop

Tree of Thoughts reasoning, deep planning, and plan management.

Install in 3 clicks

  1. Download the latest .mcpb:
    Download Yggdrasil (.mcpb)
  2. Double-click the downloaded file. Claude Desktop opens an install dialog → click Install.
  3. Restart Claude Desktop.

Requires Claude Desktop 1.8000 or later.

Try it

Ask Claude in any chat:

use sequential_thinking with 5 thoughts to analyse [your problem]

Or for structured planning:

start a deep_planning session for [your project]

Verify integrity (optional)

Each build publishes a SHA256 hash. Compare against the official sums:

shasum -a 256 ~/Downloads/yggdrasil-mcp-*.mcpb
# Compare against
# https://packages.henrychong.com/yggdrasil-mcp/SHA256SUMS

What does it do?

  • sequential_thinking — step-by-step reasoning with revision and branching
  • deep_planning — multi-phase planning sessions (init → clarify → explore → evaluate → finalize)
  • list_plans / get_plan / promote_plan / archive_plans — plan lifecycle management

Plans persist to ~/.claude/plans/. The extension makes no network calls.
